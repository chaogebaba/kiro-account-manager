# Kiro Auth Refresh Token API

使用 refresh_token 获取新的 access_token

## 请求

```
POST https://prod.us-east-1.auth.desktop.kiro.dev/refreshToken
Content-Type: application/json
```

### Request Body

```json
{
  "refreshToken": "aorAAAAAGmn7mkq3ENoExbIwgk_OdwcuxkJyaq2ol_QY6gqmwCeb6D5a4F-FWILIO_HDHJsXNynJT-XdvRzblKptIBkc0:MGQCMBuTWX3CWkyOh2dO7j0FEM4RkoLn08ZaB4sJgNZQQ8TPG/bNjhGjIBvBBoEKtBFfPQIwA5tajK2obPdZO6HZmzqucKmm0SKjSeeX8Jg8LV0Cx6nLnOGRP/IbRlfoU3aF3PAp"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| refreshToken | string | 是 | 刷新令牌 |

### 成功 (200 OK)

```json
{
  "accessToken": "aoaAAAAAGkxVbsc9qEYamDz5AxPKOmBINdU1kxbqppiqiZDYyiT3YyKx_OKo42AJnNq24JGKFUrS8Z-D8r3iPnenIBkc0:MGUCMFzYCHhjG5lS+e0ffSqISKubSx4j3AbtTnLntKnyzh46/Lvylbdhdq8Ghes5Q/GB6AIxAK0Ki19EUwf0pS2MJRcx+sX940mQLBhoTiMmRRlGhVjVK8Tser6sgEs/Wxy73IZNcw",
  "refreshToken": "aorAAAAAGmn7mkq3ENoExbIwgk_OdwcuxkJyaq2ol_QY6gqmwCeb6D5a4F-FWILIO_HDHJsXNynJT-XdvRzblKptIBkc0:MGQCMBuTWX3CWkyOh2dO7j0FEM4RkoLn08ZaB4sJgNZQQ8TPG/bNjhGjIBvBBoEKtBFfPQIwA5tajK2obPdZO6HZmzqucKmm0SKjSeeX8Jg8LV0Cx6nLnOGRP/IbRlfoU3aF3PAp",
  "expiresIn": 3600,
  "profileArn": "arn:aws:codewhisperer:us-east-1:699475941385:profile/EHGA3GRVQMUK"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| accessToken | string | 新的访问令牌 |
| refreshToken | string | 刷新令牌 (可能会更新) |
| expiresIn | number | accessToken 过期时间 (秒) |
| profileArn | string | AWS CodeWhisperer Profile ARN |

### 错误

- `401 Unauthorized` - refreshToken 已过期或无效
