# GetAvailableSubscriptionPlans

获取可用的订阅计划列表。

## 请求

```
POST https://app.kiro.dev/service/KiroWebPortalService/operation/GetAvailableSubscriptionPlans
```

### Headers

| Header | 值 | 说明 |
|--------|------|------|
| accept | application/cbor | 响应格式 |
| content-type | application/cbor | 请求格式 |
| smithy-protocol | rpc-v2-cbor | Smithy 协议 |
| authorization | Bearer {accessToken} | 访问令牌 (aoa 开头) |
| x-csrf-token | {csrfToken} | CSRF 令牌 |
| x-kiro-userid | {userId} | 用户 ID |
| x-kiro-visitorid | {visitorId} | 访客 ID |

### Cookie

```
AccessToken={accessToken}; SessionToken={sessionToken}; Idp={provider}
```

### Body

```
空（空格）
```

## 响应

### 格式: CBOR

解码后 JSON 结构:

```json
{
  "disclaimer": [
    "For any of the paid plans, turn on overages to extend your usage. Need even more usage? Upgrade your plan at any time.",
    "Prices are exclusive of applicable taxes and duties, including VAT and applicable sales tax. For customers with a Japanese billing address, use of Kiro is subject to Japanese Consumption Tax."
  ],
  "subscriptionPlans": [
    {
      "name": "KIRO_FREE",
      "title": "KIRO FREE",
      "description": "",
      "billingInterval": "per month",
      "featureHeader": "",
      "features": [
        "Agentic capabilities in the Kiro IDE",
        "50 credits",
        "Agent hooks",
        "Model context protocol (MCP)",
        "Agent steering"
      ],
      "pricing": {
        "amount": 0
      }
    }
  ]
}
```

## 字段说明

### disclaimer (免责声明)

| 字段 | 类型 | 说明 |
|------|------|------|
| disclaimer | string[] | 免责声明文本数组 |

### subscriptionPlans (订阅计划)

| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 计划代号 (如 `KIRO_FREE`, `KIRO_PRO`) |
| title | string | 显示名称 |
| description | string | 计划描述 |
| billingInterval | string | 计费周期 (如 `per month`) |
| featureHeader | string | 功能列表标题 |
| features | string[] | 功能列表 |
| pricing.amount | number | 价格 (0 = 免费) |

## 注意

- 此接口返回 CBOR 格式数据，需要解码
- 需要有效的 AccessToken 和 CSRF Token
- 响应包含所有可用的订阅计划（Free/Pro/Pro+）
