# ExchangeToken - 交换 Token

## 请求

```
POST https://app.kiro.dev/service/KiroWebPortalService/operation/ExchangeToken
Content-Type: application/cbor
smithy-protocol: rpc-v2-cbor
```

## 参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| idp | string | 是 | 登录提供商: Google / Github / BuilderId |
| code | string | 是 | OAuth 授权码 |
| codeVerifier | string | 是 | PKCE code_verifier |
| redirectUri | string | 是 | https://app.kiro.dev/signin/oauth |
| state | string | 是 | InitiateLogin 返回的 state (AWS 编码后的值) |

## 响应 Body (CBOR)

| 字段 | 类型 | 说明 |
|------|------|------|
| accessToken | string | 访问令牌 (aoa开头) |
| csrfToken | string | CSRF 令牌 |
| expiresIn | number | 过期时间(秒)，通常 604800 (7天) |
| state | string | 原始 state |

> 注意：`profileArn` 只有 Google/Github 返回，BuilderId 不返回

## Set-Cookie

| Cookie | 说明 | 格式 | Max-Age |
|--------|------|------|---------|
| AccessToken | 访问令牌 | aoa开头 | 604800 (7天) |
| SessionToken | 会话令牌 (仅 BuilderId) | AAAAD开头 | 604800 (7天) |
| RefreshToken | 刷新令牌 (仅 Google/Github) | aor开头 | 604800 (7天) |
| Idp | 登录提供商 | Google/Github/BuilderId | 604800 (7天) |

> **重要区别**：
> - BuilderId 返回 `SessionToken` cookie
> - Google/Github 返回 `RefreshToken` cookie
