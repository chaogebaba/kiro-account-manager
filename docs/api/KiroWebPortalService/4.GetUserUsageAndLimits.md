# GetUserUsageAndLimits - 获取用量和限额

获取用户配额使用情况、订阅信息、邮箱等。

## 请求

**URL**: `POST https://app.kiro.dev/service/KiroWebPortalService/operation/GetUserUsageAndLimits`

**Headers**:
```
Content-Type: application/cbor
Accept: application/cbor
smithy-protocol: rpc-v2-cbor
authorization: Bearer <accessToken>
x-csrf-token: <csrfToken>
Cookie: AccessToken=<accessToken>; SessionToken=<sessionToken>; Idp=<idp>
```

**Body (CBOR)**:
```json
{
  "isEmailRequired": true,
  "origin": "KIRO_IDE"
}
```

## 字段说明

### subscriptionInfo
| 字段 | 说明 |
|-----|------|
| type | 订阅类型 |
| subscriptionTitle | 显示名称 (KIRO PRO+) |
| overageCapability | 超额能力 |
| upgradeCapability | 升级能力 |

### usageBreakdownList
| 字段 | 说明 |
|-----|------|
| resourceType | 资源类型 (CREDIT) |
| usageLimit | 配额上限 |
| currentUsage | 当前使用量 |
| overageRate | 超额费率 |
| overageCap | 超额上限 |
| currency | 货币 (USD) |

### freeTrialInfo
| 字段 | 说明 |
|-----|------|
| freeTrialStatus | 状态 (ACTIVE/EXPIRED) |
| usageLimit | 试用配额 |
| currentUsage | 试用已用 |
| freeTrialExpiry | 过期时间戳 |

### bonuses
| 字段 | 说明 |
|-----|------|
| bonusCode | 奖励码 |
| displayName | 显示名称 |
| usageLimit | 奖励配额 |
| currentUsage | 奖励已用 |
| expiresAt | 过期时间戳 |
| status | 状态 (ACTIVE) |

### userInfo
| 字段 | 说明 |
|-----|------|
| email | 用户邮箱 |
| userId | 用户 ID |

## Idp 值

| 登录方式 | Idp |
|---------|-----|
| BuilderId | `BuilderId` |
| Google | `Google` |
| GitHub | `Github` |

## 示例 (fetch)

```javascript
fetch("https://app.kiro.dev/service/KiroWebPortalService/operation/GetUserUsageAndLimits", {
  method: "POST",
  headers: {
    "accept": "application/cbor",
    "content-type": "application/cbor",
    "smithy-protocol": "rpc-v2-cbor",
    "authorization": "Bearer aoaAAAAA...",
    "x-csrf-token": "Hx9fFJVj+1v29JyhByW3MX7pfmrve3lOyfKdjQdCmf4=",
    "cookie": "AccessToken=aoaAAAAA...; SessionToken=AAAADmtl...; Idp=BuilderId"
  },
  body: cbor_encode({ isEmailRequired: true, origin: "KIRO_IDE" })
});
```

## 注意

- 需要 `authorization: Bearer <accessToken>` Header
- 需要三个 Cookie: `AccessToken`, `SessionToken`, `Idp`
- `isEmailRequired: true` 时响应包含 `userInfo.email`
