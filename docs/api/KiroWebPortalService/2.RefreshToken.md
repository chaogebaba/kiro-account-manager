# RefreshToken - 刷新令牌

刷新 Web OAuth 的 AccessToken。

## 请求

**URL**: `POST https://app.kiro.dev/service/KiroWebPortalService/operation/RefreshToken`

**Headers**:
```
Content-Type: application/cbor
Accept: application/cbor
smithy-protocol: rpc-v2-cbor
x-csrf-token: <csrfToken>
Cookie: AccessToken=<accessToken>; <SessionCookie>=<sessionToken>; Idp=<idp>
```

> **Cookie 名称区别**：
> - BuilderId: `SessionToken`
> - Google/Github: `RefreshToken`

**Body (CBOR)**:
```json
{
  "csrfToken": "<csrfToken>"
}
```

## 响应

**Status**: 200 OK

**Body (CBOR)**:
```json
{
  "accessToken": "aoaAAAAAGkzFTg3FIdSpgOaEExQnZToqz42ZngK6riV...",
  "csrfToken": "Hx9fFJVj+1v29JyhByW3MX7pfmrve3lOyfKdjQdCmf4=",
  "expiresIn": 3600,
  "profileArn": "arn:aws:codewhisperer:us-east-1:..."
}
```

> 注意：`profileArn` 只有 Google/Github 返回，BuilderId 不返回

## Set-Cookie

### BuilderId

| Cookie | 格式 | Max-Age | 说明 |
|--------|------|---------|------|
| AccessToken | aoa开头 | 604800 (7天) | 新的访问令牌 |
| SessionToken | AAAA开头 | 604800 (7天) | 会话令牌 (用于下次刷新) |
| Idp | BuilderId | 604800 (7天) | 登录提供商 |

### Google/Github

| Cookie | 格式 | Max-Age | 说明 |
|--------|------|---------|------|
| AccessToken | aoa开头 | 604800 (7天) | 新的访问令牌 |
| RefreshToken | aor开头 | 604800 (7天) | 刷新令牌 (用于下次刷新) |
| Idp | Google/Github | 604800 (7天) | 登录提供商 |

所有 Cookie 属性: `HttpOnly; Secure; SameSite=Lax; Path=/`

## Idp 值

| 登录方式 | Idp | Session Cookie |
|---------|-----|----------------|
| BuilderId | `BuilderId` | `SessionToken` |
| Google | `Google` | `RefreshToken` |
| Github | `Github` | `RefreshToken` |

## 示例

### BuilderId

```javascript
fetch("https://app.kiro.dev/service/KiroWebPortalService/operation/RefreshToken", {
  method: "POST",
  headers: {
    "accept": "application/cbor",
    "content-type": "application/cbor",
    "smithy-protocol": "rpc-v2-cbor",
    "x-csrf-token": "Hx9fFJVj+1v29JyhByW3MX7pfmrve3lOyfKdjQdCmf4=",
    "cookie": "AccessToken=aoaAAAAA...; SessionToken=AAAADmtl...; Idp=BuilderId"
  },
  body: cbor_encode({ csrfToken: "Hx9fFJVj+1v29JyhByW3MX7pfmrve3lOyfKdjQdCmf4=" })
});
```

### Google/Github

```javascript
fetch("https://app.kiro.dev/service/KiroWebPortalService/operation/RefreshToken", {
  method: "POST",
  headers: {
    "accept": "application/cbor",
    "content-type": "application/cbor",
    "smithy-protocol": "rpc-v2-cbor",
    "x-csrf-token": "9Bd3FZZb1JoAvLvpUYmExKIqRTOAe0frjPpKwpe8Ql8=",
    "cookie": "AccessToken=aoaAAAAA...; RefreshToken=aorAAAAA...; Idp=Google"
  },
  body: cbor_encode({ csrfToken: "9Bd3FZZb1JoAvLvpUYmExKIqRTOAe0frjPpKwpe8Ql8=" })
});
```

## 注意

- 需要三个 Cookie: `AccessToken`, `SessionToken`/`RefreshToken`, `Idp`
- **BuilderId 用 `SessionToken`，Google/Github 用 `RefreshToken`**
- Session Cookie 从 ExchangeToken 的 Set-Cookie 响应头获取
- `csrfToken` 同时在 Header (`x-csrf-token`) 和 Body 中传递
    "x-csrf-token": "Hx9fFJVj+1v29JyhByW3MX7pfmrve3lOyfKdjQdCmf4=",
    "cookie": "AccessToken=aoaAAAAA...; SessionToken=AAAADmtl...; Idp=BuilderId"
  },
  body: cbor_encode({ csrfToken: "Hx9fFJVj+1v29JyhByW3MX7pfmrve3lOyfKdjQdCmf4=" })
});
```

## 注意

- 需要三个 Cookie: `AccessToken`, `SessionToken`, `Idp`
- `SessionToken` 从 ExchangeToken 的 Set-Cookie 响应头获取
- `csrfToken` 同时在 Header 和 Body 中传递
