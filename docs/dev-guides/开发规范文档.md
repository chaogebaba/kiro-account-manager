# Kiro Account Manager 开发规范文档

基于 Tauri 构建的桌面应用（Rust 后端 + React 前端），用于管理 Kiro IDE 账号。

---

## 整体界面结构

应用采用左侧边栏 + 右侧主内容区的布局：

```
┌──────────────────────────────────────────────────────────────┐
│  ┌─────────────┐  ┌────────────────────────────────────────┐ │
│  │   侧边栏    │  │              主内容区                   │ │
│  │   Sidebar   │  │              (各页面)                   │ │
│  │             │  │                                        │ │
│  │  - 首页     │  │                                        │ │
│  │  - 账号管理 │  │                                        │ │
│  │  - Kiro配置 │  │                                        │ │
│  │  - 登录     │  │                                        │ │
│  │  - 设置     │  │                                        │ │
│  │  - 关于     │  │                                        │ │
│  │             │  │                                        │ │
│  │  [主题切换] │  │                                        │ │
│  │  [版本号]   │  │                                        │ │
│  └─────────────┘  └────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

### 侧边栏 (Sidebar.jsx)

- Logo + 应用名称
- 导航菜单：首页、账号管理、Kiro配置、Desktop OAuth、设置、关于
- Kiro IDE 连接状态卡片
- 主题切换按钮（浅色/深色/紫色/绿色）
- 版本号显示

## 页面功能说明

### 1. 首页 (Home.jsx)

显示账号概览和当前登录状态。

**功能：**
- 统计卡片：总账号数、正常账号、PRO账号、配额使用率
- 当前登录账号：显示本地 Kiro IDE 的登录状态
- 配额总览：所有账号的总配额使用情况
- 当前账号配额详情：基础额度、试用额度、奖励额度明细

---

### 2. 账号管理 (AccountManager/index.jsx)

管理所有 Kiro 账号，支持卡片/列表双视图。

**功能：**
- 视图切换：卡片网格 / 列表表格
- 搜索：按邮箱或备注搜索
- 筛选：按订阅类型、状态、标签筛选
- 排序：按使用率、添加时间、试用到期排序
- 添加账号：支持 Social（Google/GitHub）和 IdC（BuilderId）
- 导入/导出：JSON 格式批量操作
- 批量操作：刷新、删除、打标签
- 单个操作：切换、刷新、详情、编辑、删除

**子组件：**
- `AccountHeader.jsx` - 顶部工具栏
- `AccountTable.jsx` - 卡片网格容器
- `AccountListView.jsx` - 列表表格视图
- `AccountCard.jsx` - 单个账号卡片
- `AccountPagination.jsx` - 分页控件
- `AddAccountModal.jsx` - 添加账号弹窗
- `ImportAccountModal.jsx` - 导入账号弹窗
- `EditAccountModal.jsx` - 编辑备注弹窗
- `BatchTagModal.jsx` - 批量打标签弹窗
- `GroupTagManager.jsx` - 标签管理器
- `RefreshProgressModal.jsx` - 刷新进度弹窗
- `ConfirmDialog.jsx` - 确认弹窗

---

### 3. Kiro 配置 (KiroConfig/index.jsx)

管理 Kiro IDE 的 MCP 服务器和 Steering 规则。

**Tab 切换：**
- MCP 服务器面板
- Steering 规则面板

#### 3.1 MCP 服务器面板 (MCPPanel.jsx)

**功能：**
- 查看所有 MCP 服务器配置
- 添加服务器（手动配置或从模板选择）
- 编辑服务器配置（命令、参数、环境变量、自动批准工具）
- 启用/禁用服务器
- 删除服务器

#### 3.2 Steering 规则面板 (SteeringPanel.jsx)

**功能：**
- 查看 `~/.kiro/steering/` 目录下的规则文件
- 编辑规则内容
- 创建新规则
- 删除规则

---

### 4. Desktop OAuth 登录 (Login.jsx)

通过桌面 OAuth 流程登录。

**功能：**
- 支持 Google、GitHub、AWS Builder ID 三种登录方式
- 点击后打开系统浏览器进行 OAuth 授权
- 通过 Deep Link 回调完成登录

---

### 5. 设置 (Settings.jsx)

配置应用和 Kiro IDE 设置。

**功能：**
- 主题设置：浅色/深色/紫色/绿色
- 模型设置：选择 AI 模型，可锁定防止被修改
- 代码库索引：开启/关闭代码库索引
- 信任命令：开启/关闭信任所有命令
- 账号设置：自动刷新 Token、切换时自动更换机器码
- 隐私模式：隐藏敏感信息
- 浏览器设置：配置 OAuth 登录使用的浏览器
- 代理设置：配置 HTTP 代理
- Kiro IDE 信息：查看和重置机器 ID
- 系统机器码：查看、复制、备份、恢复、重置

---

### 6. 关于 (About.jsx)

显示应用信息和赞赏。

**功能：**
- 显示版本号
- 检查更新、下载更新
- 技术栈信息
- GitHub 和 QQ 群链接
- 赞赏二维码

## 数据存储

### 存储路径

**Windows:**
- 账号数据: `%APPDATA%\.kiro-account-manager\accounts.json`
- 应用设置: `%APPDATA%\.kiro-account-manager\settings.json`
- 机器码备份: `%APPDATA%\.kiro-account-manager\machine-guid-backup.json`
- MCP配置: `~/.kiro/settings/mcp.json`
- Steering规则: `~/.kiro/steering/*.md`

**macOS/Linux:**
- 账号数据: `~/.kiro-account-manager/accounts.json`
- 应用设置: `~/.kiro-account-manager/settings.json`
- MCP配置: `~/.kiro/settings/mcp.json`
- Steering规则: `~/.kiro/steering/*.md`

## 前后端通信

使用 `invoke()` 调用 Rust 命令：

```javascript
import { invoke } from '@tauri-apps/api/core'

// 获取账号列表
const accounts = await invoke('get_accounts')

// 同步账号
const updated = await invoke('sync_account', { id: account.id })

// 切换账号
await invoke('switch_kiro_account', { params: { ... } })
```

## 账号类型说明

### Social 账号（Google/GitHub）

- refreshToken 以 `aor` 开头
- 使用 Kiro Desktop Auth API 刷新
- 不需要 clientId/clientSecret
- 有 profileArn 字段

### IdC 账号（BuilderId/Enterprise）

- refreshToken 以 `eyJ` 开头（JWT 格式）
- 使用 AWS OIDC API 刷新
- 需要 clientId、clientSecret、region
- 有 clientIdHash 字段

## 状态管理

### 前端状态
- React Context 管理 UI 状态（主题、弹窗、隐私模式）
- 组件内 useState 管理局部状态

### 后端状态
- Tauri AppState（Mutex 包装）管理后端状态
- AccountStore 管理账号数据
- AuthState 管理认证状态

```rust
pub struct AppState {
    pub store: Mutex<AccountStore>,
    pub auth: AuthState,
    pub pending_login: Mutex<Option<PendingLogin>>,
}
```
