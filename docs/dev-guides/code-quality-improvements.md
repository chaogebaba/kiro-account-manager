## 📝 问题详解

### 1. format! 可以直接使用变量

**问题**：
```rust
// ❌ 不推荐
format!("Error: {}", error)

// ✅ 推荐
format!("Error: {error}")
```

**影响**：代码可读性，无性能影响

**修复优先级**：低（可选）

---

### 2. 长行（超过 120 字符）

**问题**：
```rust
// ❌ 超过 120 字符
let existing_idx = find_existing_account_idx(&store.accounts, &Some(final_email.clone()), &idp, &final_refresh_token, &user_id);

// ✅ 换行
let existing_idx = find_existing_account_idx(
    &store.accounts,
    &Some(final_email.clone()),
    &idp,
    &final_refresh_token,
    &user_id
);
```

**影响**：代码可读性

**修复优先级**：低（可选）

---

### 3. 类型转换精度损失

**问题**：
```rust
// ❌ i64 → f32 会损失精度
let percentage = (used as f32 / total as f32) * 100.0;

// ✅ 使用 f64
let percentage = (used as f64 / total as f64) * 100.0;
```

**影响**：数值精度

**修复优先级**：中（建议修复）

---

### 4. 冗余闭包

**问题**：
```rust
// ❌ 冗余闭包
.map(|x| some_function(x))

// ✅ 直接传递函数
.map(some_function)
```

**影响**：代码简洁性

**修复优先级**：低（可选）
