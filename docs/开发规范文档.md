# Kiro Account Manager 开发规范文档

基于 Tauri 构建的桌面应用（Rust 后端 + React 前端），用于管理 Kiro IDE 账号。

---

## 整体界面结构

应用采用左侧边栏 + 右侧主内容区的布局：

```
┌──────────────────────────────────────────────────────────────┐
│  ┌─────────────┐  ┌────────────────────────────────────────┐ │
│  │             │  │                                        │ │
│  │   侧边栏    │  │              主内容区                   │ │
│  │   Sidebar   │  │              (各页面)                   │ │
│  │             │  │                                        │ │
│  │  - 首页     │  │                                        │ │
│  │  - 账号管理 │  │                                        │ │
│  │  - Kiro配置 │  │                                        │ │
│  │  - 登录     │  │                                        │ │
│  │  - 设置     │  │                                        │ │
│  │  - 关于     │  │                                        │ │
│  │             │  │                                        │ │
│  │  [主题切换] │  │                                        │ │
│  │  [版本号]   │  │                                        │ │
│  └─────────────┘  └────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

### 侧边栏 (Sidebar.jsx)

- Logo + 应用名称
- 导航菜单：首页、账号管理、Kiro配置、Desktop OAuth、Web Portal OAuth、设置、关于
- Kiro IDE 连接状态卡片（显示当前登录的 provider）
- 主题切换按钮（浅色/深色/紫色/绿色）
- 版本号显示

**卡片内容说明：**
- 左上角：选择框
- 右上角：状态标签（正常/封禁/异常）
- 头像区：首字母 + 邮箱 + 复制按钮 + 备注标签
- 订阅类型：PRO+/PRO/Free 徽章 + 登录方式（Google/GitHub/BuilderId）
- 当前使用：绿色边框 + "当前使用" 标签
- 配额进度：使用量百分比 + 进度条 + 已用/总量 + 剩余 + 重置日期
- Token 过期时间：显示过期状态
- 操作按钮：切换、刷新、详情、编辑备注、删除

**卡片状态样式：**
- 正常账号：默认边框
- 当前使用：绿色边框 + 绿色光晕
- 已封禁：红色边框 + 红色光晕
- 异常状态：橙色边框 + 橙色光晕
- 选中状态：紫色边框 + 紫色背景

**功能：**
- 搜索：按邮箱或备注搜索
- 添加账号：支持 Social（Google/GitHub）和 IdC（BuilderId）两种方式
- 导入账号：从 JSON 文件批量导入
- 导出账号：导出选中或全部账号为 JSON
- 刷新全部：批量刷新所有账号的 token 和配额（显示进度条）
- 批量删除：删除选中的账号
- 单个操作：切换、刷新、查看详情、编辑备注、删除

**子组件：**
- `AccountHeader.jsx` - 顶部工具栏（标题、搜索、操作按钮、刷新进度）
- `AccountTable.jsx` - 卡片网格容器（全选控制 + 卡片列表）
- `AccountCard.jsx` - 单个账号卡片
- `AccountPagination.jsx` - 分页控件
- `AddAccountModal.jsx` - 添加账号弹窗
- `ImportAccountModal.jsx` - 导入账号弹窗
- `EditAccountModal.jsx` - 编辑备注弹窗
- `RefreshProgressModal.jsx` - 刷新进度弹窗
- `ConfirmDialog.jsx` - 确认弹窗（切换成功/失败提示）

## 数据存储

### 客户端账号文件存放路径
- Windows: `%APPDATA%\.kiro-account-manager\accounts.json`
- macOS: `~/Library/Application Support/.kiro-account-manager/accounts.json`

### 账号数据模板

```json
{
  "id": "uuid",
  "email": "user@example.com",
  "label": "账号备注",
  "status": "正常",
  "addedAt": "2025/01/01 12:00:00",
  "accessToken": "...",
  "refreshToken": "...",
  "expiresAt": "2025/01/01 13:00:00",
  "provider": "Google",
  "userId": "...",
  "clientId": null,
  "clientSecret": null,
  "region": null,
  "usageData": {}
}
```

## Tauri 命令列表

### 账号管理命令

| 命令 | 功能 | 参数 |
|------|------|------|
| `get_accounts` | 获取所有账号 | 无 |

## 账号类型说明

### Social 账号（Google/GitHub）

- refreshToken 以 `aor` 开头
- 使用 Desktop OAuth API 刷新
- 不需要 clientId/clientSecret

### IdC 账号（BuilderId/Enterprise）

- refreshToken 以 `eyJ` 开头（JWT格式）
- 使用 AWS OIDC API 刷新
- 需要 clientId、clientSecret、region
