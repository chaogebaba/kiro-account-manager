# 发布新版本流程

## 仓库说明

- **私有仓库**: `hj01857655/kiro-account-manager_dev` - 存放源代码
- **公开仓库**: `hj01857655/kiro-account-manager` - 用于触发 Actions 构建和发布 Release

## 发布步骤

### 1. 在私有仓库完成开发

```bash
# 更新版本号（三个文件要一致）
# - package.json
# - src-tauri/tauri.conf.json  
# - src-tauri/Cargo.toml

# 提交并推送
git add -A
git commit -m "v1.x.x: 更新内容描述"
git push

# 在私有仓库打 tag（必须！公开仓库会从这个 tag checkout 代码）
git tag v1.x.x
git push origin v1.x.x
```

### 2. 在公开仓库打 tag 触发构建

```bash
# 获取公开仓库 releases 分支最新 commit sha
$sha = gh api repos/hj01857655/kiro-account-manager/commits/releases --jq ".sha"

# 创建 tag（替换 VERSION 为实际版本号，如 1.3.1）
gh api repos/hj01857655/kiro-account-manager/git/refs -f ref="refs/tags/vVERSION" -f sha="$sha"
```

### 3. 查看构建状态

```bash
# 列出最近的 Actions 运行
gh run list --repo hj01857655/kiro-account-manager -L 5

# 实时查看构建进度（替换 RUN_ID）
gh run watch RUN_ID --repo hj01857655/kiro-account-manager
```

### 4. 构建完成

Actions 完成后会自动：
- 创建 GitHub Release
- 上传构建产物（.msi, .exe, .dmg 等）
- 生成 latest.json 用于自动更新

## 常用命令

### 查看公开仓库所有 tag

```bash
gh api repos/hj01857655/kiro-account-manager/tags --jq ".[].name"
```

### 删除 tag（如果需要重新打）

```bash
gh api -X DELETE repos/hj01857655/kiro-account-manager/git/refs/tags/vVERSION
```

### 删除 Release

```bash
gh release delete vVERSION --repo hj01857655/kiro-account-manager --yes
```

### 删除失败的 Actions 记录

```bash
# 删除所有失败的 runs
gh run list --repo hj01857655/kiro-account-manager -L 10 --json databaseId,conclusion | ConvertFrom-Json | Where-Object { $_.conclusion -eq "failure" } | ForEach-Object { gh run delete $_.databaseId --repo hj01857655/kiro-account-manager }

# 删除指定 run
gh run delete RUN_ID --repo hj01857655/kiro-account-manager
```

### 取消正在运行的 Actions

```bash
# 先获取 run id
gh run list --repo hj01857655/kiro-account-manager --json databaseId,status

# 取消指定的 run
gh run cancel RUN_ID --repo hj01857655/kiro-account-manager
```

## 注意事项

1. **私有仓库必须打 tag** - 公开仓库的 workflow 会从私有仓库 checkout 对应 tag 的代码
2. **版本号要一致** - tag 名称要和代码里的版本号对应
3. **不要把源代码推送到公开仓库** - 公开仓库只用于触发构建
4. **Actions 额度** - 公开仓库 Actions 免费无限制
5. **tag 冲突** - 如果 tag 已存在，需要先删除再重新创建
