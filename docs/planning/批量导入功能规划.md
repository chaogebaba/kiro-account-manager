# 批量导入账号功能规划

## 功能概述

在 Kiro Account Manager 中添加批量导入账号功能，支持通过 JSON 文件或粘贴 JSON 内容批量添加账号。

## JSON 格式

### Social 账号（Google/GitHub）

```json
{
  "refreshToken": "aor_xxx",
  "provider": "Google"
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| refreshToken | ✓ | 刷新令牌，`aor` 开头 |
| provider | ✓ | `Google` 或 `GitHub` |

### IdC 账号（BuilderId/Enterprise）

```json
{
  "refreshToken": "eyJ_xxx",
  "clientId": "xxx",
  "clientSecret": "xxx",
  "provider": "BuilderId"
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| refreshToken | ✓ | 刷新令牌，`eyJ` 开头（JWT） |
| clientId | ✓ | 客户端 ID |
| clientSecret | ✓ | 客户端密钥 |
| provider | ✓ | `BuilderId` 或 `Enterprise` |

### 完整导入文件示例

```json
[
  {"refreshToken": "aor_xxx", "provider": "Google"},
  {"refreshToken": "aor_yyy", "provider": "GitHub"},
  {"refreshToken": "eyJ_xxx", "clientId": "c1", "clientSecret": "s1", "provider": "BuilderId"},
  {"refreshToken": "eyJ_yyy", "clientId": "c2", "clientSecret": "s2", "provider": "Enterprise"}
]
```

## 自动识别规则

| Token 格式 | 账号类型 | Provider |
|-----------|---------|----------|
| `aor` 开头 | Social | Google/GitHub |
| `eyJ` 开头 | IdC | BuilderId/Enterprise |

## 校验规则

1. **refreshToken** - 必须存在
2. **provider** - 必须是 Google/GitHub/BuilderId/Enterprise 之一
3. **provider 与 token 格式匹配**
   - provider=Google/GitHub → token 必须 `aor` 开头
   - provider=BuilderId/Enterprise → token 必须 `eyJ` 开头
4. **IdC 账号必须有 clientId 和 clientSecret**

## 技术实现

### 后端（已有）

- `add_account_by_social` - 添加 Google/GitHub 账号
- `add_account_by_idc` - 添加 BuilderId/Enterprise 账号

### 前端（待实现）

**新增文件：**
```
src/components/AccountManager/
└── ImportAccountModal.jsx    # 批量导入弹窗
```

**修改文件：**
- `AccountHeader.jsx` - 添加导入按钮
- `index.jsx` - 添加导入弹窗状态和逻辑

### 导入流程

```
用户点击 [导入] 按钮
    ↓
打开 ImportAccountModal
    ↓
用户选择文件或粘贴 JSON
    ↓
前端解析 JSON，校验格式
    ↓
显示解析结果（有效/无效条数）
    ↓
用户点击 [导入]
    ↓
显示进度条
    ↓
逐个调用后端添加账号
  ├─ Social → add_account_by_social
  └─ IdC → add_account_by_idc
    ↓
显示导入结果（成功/失败）
    ↓
关闭弹窗，刷新账号列表
```

## 实现步骤

1. 创建 `ImportAccountModal.jsx` 组件
2. 实现文件选择和 JSON 解析
3. 实现校验逻辑
4. 实现导入进度和结果显示
5. 在 `AccountHeader.jsx` 添加导入按钮
6. 在 `index.jsx` 集成导入功能

## 导入导出图标说明

图标设计遵循"数据流向"视角：

| 功能 | 图标 | 说明 |
|------|------|------|
| 导入 | Upload ↑ | 数据从外部文件"上传"到应用中，就像把文件上传到服务器 |
| 导出 | Download ↓ | 数据从应用"下载"到本地文件，就像从服务器下载文件 |

这是业界通用的约定，大多数软件（Excel、浏览器、各种管理工具）都采用这种设计。

## 导出功能说明

- 不选中任何账号 → 导出全部账号
- 选中了账号 → 只导出选中的账号
- 文件名格式：`kiro-accounts[-数量]-日期.json`
