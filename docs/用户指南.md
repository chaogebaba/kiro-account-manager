# Kiro Account Manager 用户指南

## 简介

Kiro Account Manager 是一款桌面应用，用于管理多个 Kiro IDE 账号，支持配额监控、一键切换、批量导入导出等功能。

## 安装

- Windows: 下载 `.msi` 或 `.exe` 安装包
- macOS: 下载 `.dmg` 安装包

## 功能说明

### 账号管理

**添加账号**
- 桌面授权登录：支持 Google、GitHub、AWS Builder ID
- 网页授权登录：通过 WebView 窗口登录
- 手动导入：粘贴 refreshToken 添加

**批量导入**

JSON 格式（Social 账号）：
```json
[
  {
    "refreshToken": "aor...",
    "provider": "Google"
  }
]
```

JSON 格式（IdC 账号）：
```json
[
  {
    "refreshToken": "aor...",
    "clientId": "xxx",
    "clientSecret": "xxx",
    "region": "us-east-1",
    "provider": "BuilderId"
  }
]
```

SSO Token 导入：
1. 打开 view.awsapps.com/start 并登录
2. F12 → Application → Cookies
3. 复制 `x-amz-sso_authn` 的值

**账号操作**
- 切换：点击卡片上的「切换」按钮
- 刷新：更新 Token 和配额信息
- 导出：导出账号数据为 JSON 文件

### 规则配置

**MCP 服务器**
- 管理 `~/.kiro/settings/mcp.json`
- 支持添加、编辑、启用/禁用服务器

**Powers**
- 查看已安装的 Powers
- 路径：`~/.kiro/powers/registry.json`

**Steering 规则**
- 管理 `~/.kiro/steering/*.md` 规则文件
- 支持创建、编辑、删除

### 设置

- 主题：浅色 / 深色 / 紫色 / 绿色
- 代理：配置 HTTP 代理
- 自动刷新：定时刷新过期 Token
- 机器码管理：重置 Kiro IDE 机器 ID

## 数据存储

| 数据 | 路径 |
|------|------|
| 账号数据 | `%APPDATA%\.kiro-account-manager\accounts.json` |
| 应用设置 | `%APPDATA%\.kiro-account-manager\settings.json` |

## 常见问题

**Q: 登录失败怎么办？**
A: 检查网络连接，尝试使用代理或切换登录方式。

**Q: Token 过期了怎么办？**
A: 点击刷新按钮，或开启自动刷新功能。

**Q: 如何备份账号？**
A: 使用导出功能，将账号数据保存为 JSON 文件。
