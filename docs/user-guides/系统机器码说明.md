# 系统机器码说明

## 概述

系统机器码是操作系统级的唯一机器标识，在系统安装时生成，重装系统才会改变。

Kiro Desktop 使用 `node-machine-id` 库获取机器码，我们的实现与其完全一致。

## 各平台获取方式

### Windows
- 来源：注册表 `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Cryptography\MachineGuid`
- 格式：UUID（如 `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`）
- 修改：需要管理员权限
- 重置机器 ID：✅ 支持

### macOS
- 来源：优先读取 `~/Library/Application Support/Kiro/machineid` 文件，不存在则读取 `IOPlatformUUID`
- 格式：UUID
- 修改：写入 `~/Library/Application Support/Kiro/machineid` 文件
- 重置机器 ID：✅ 支持（通过写入 Kiro IDE 的 machineid 文件）
- 说明：Kiro IDE 会优先读取 machineid 文件，如果不存在才使用硬件 UUID

### Linux
- 来源：`/etc/machine-id` 或 `/var/lib/dbus/machine-id`
- 格式：32位十六进制字符串
- 修改：需要 root 权限
- 重置机器 ID：✅ 支持

## Kiro Desktop 源码参考

```javascript
import { machineIdSync } from "node-machine-id"

const DEFAULT_MACHINE_ID = "UNDETERMINED_MACHINE_ID"

function getMachineId() {
  try {
    return machineIdSync()
  } catch (_e) {
    return vscode.env.machineId || DEFAULT_MACHINE_ID
  }
}
```

## 我们的实现

文件：`src-tauri/src/commands/machine_guid_cmd.rs`

功能：
- `get_system_machine_guid` - 获取当前机器码
- `backup_machine_guid` - 备份机器码
- `restore_machine_guid` - 恢复备份的机器码
- `reset_system_machine_guid` - 生成新的随机机器码
- `set_custom_machine_guid` - 设置自定义机器码

## 用途

Kiro 使用机器码来：
- 标识设备
- 配额限制（每台设备的使用量统计）
- 防止滥用
