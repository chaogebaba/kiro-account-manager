## 安装

### Windows

1. 从 [GitHub Releases](https://github.com/hj01857655/kiro-account-manager/releases/latest) 下载 `.msi` 安装包
2. 双击运行安装程序
3. 按照向导完成安装
4. 首次运行可能需要安装 WebView2（Win11 已内置）

### macOS

1. 下载 `.dmg` 文件
2. 打开 dmg，将应用拖入 Applications 文件夹
3. 首次运行时右键点击应用，选择"打开"（绕过安全检查）

### Linux

**Debian/Ubuntu (.deb)**
```bash
sudo dpkg -i kiro-account-manager_*.deb
sudo apt-get install -f  # 安装依赖
```

**通用 (.AppImage)**
```bash
chmod +x kiro-account-manager_*.AppImage
./kiro-account-manager_*.AppImage
```

## 首次使用

### 1. 启动应用

首次启动会看到首页，显示：
- 账号统计（总数、正常、封禁）
- 当前登录账号信息
- 配额总览

### 2. 添加第一个账号

有两种方式添加账号：

#### 方式一：Desktop OAuth 登录

1. 点击侧边栏"Desktop OAuth"
2. 选择登录方式：
   - Google
   - GitHub
   - BuilderId
3. 点击"开始授权"
4. 在弹出的浏览器中完成登录
5. 授权成功后自动添加到账号列表

#### 方式二：导入 JSON 文件

1. 进入"账号管理"页面
2. 点击"导入"按钮
3. 选择导入格式：
   - Social 格式（Google/GitHub）
   - IdC 格式（AWS IAM Identity Center）
4. 选择 JSON 文件
5. 确认导入

## 账号管理

### 查看账号列表

**卡片视图**（默认）
- 显示账号头像、邮箱、订阅类型
- 配额进度条（主配额/试用/奖励）
- Token 过期时间倒计时
- 状态标识（正常/封禁/当前使用）

**列表视图**
- 紧凑的表格展示
- 适合管理大量账号

切换视图：点击右上角的视图切换按钮

### 搜索和筛选

**搜索**
- 支持按邮箱、备注搜索
- 实时过滤结果

**筛选**
- 订阅类型：Free / PRO / PRO+
- 状态：正常 / 封禁
- 标签：按自定义标签筛选

**排序**
- 使用率（配额使用百分比）
- 添加时间
- 试用到期时间
- 三态排序：降序 → 升序 → 取消

### 账号操作

**单个账号操作**（右键菜单）
- 切换账号：切换到该账号并重置机器 ID
- 刷新 Token：更新 Token 和配额信息
- 查看详情：查看完整账号信息
- 编辑备注：添加或修改备注
- 复制信息：复制邮箱、Token 等
- 删除账号：从列表中移除

**批量操作**
1. 勾选多个账号
2. 点击批量操作按钮：
   - 批量刷新：同时刷新多个账号
   - 批量删除：删除选中的账号
   - 批量打标签：为选中账号添加标签

### 标签管理

**创建标签**
1. 点击"标签管理"按钮
2. 输入标签名称
3. 选择标签颜色
4. 点击"添加"

**使用标签**
- 单个账号：右键菜单 → 编辑标签
- 批量操作：勾选账号 → 批量打标签

**筛选标签**
- 点击筛选区域的标签
- 只显示包含该标签的账号

### 导出账号

1. 点击"导出"按钮
2. 选择导出格式：
   - Social 格式
   - IdC 格式
3. 选择保存位置
4. 导出为 JSON 文件

## Kiro 配置

### MCP 服务器管理

**查看 MCP 配置**
1. 进入"Kiro 配置"页面
2. 切换到"MCP 服务器"标签
3. 查看已配置的 MCP 服务器列表

**添加 MCP 服务器**
1. 点击"添加 MCP"按钮
2. 选择模板或自定义：
   - 从模板选择（推荐）
   - 手动输入配置
3. 填写配置信息：
   - 服务器名称
   - 命令
   - 参数
   - 环境变量
4. 点击"保存"

**编辑/删除 MCP**
- 点击服务器卡片的操作按钮
- 选择"编辑"或"删除"

**启用/禁用 MCP**
- 点击服务器卡片的开关
- 禁用后不会加载该服务器

### Steering 规则管理

**查看规则**
1. 切换到"Steering 规则"标签
2. 查看规则列表（全局/工作区）

**编辑规则**
1. 点击规则卡片
2. 在编辑器中修改内容
3. 点击"保存"

**规则类型**
- 全局规则：`~/.kiro/steering/*.md`
- 工作区规则：`.kiro/steering/*.md`

## 设置

### 外观设置

**主题**
- 浅色（Light）
- 深色（Dark）
- 紫色（Purple）
- 绿色（Green）

### 账号设置

**Token 自动刷新**
- 开启后定时刷新所有账号 Token
- 可设置刷新间隔（分钟）

**切号自动重置机器 ID**
- 开启后切换账号时自动重置
- 避免机器 ID 冲突

**隐私模式**
- 开启后隐藏敏感信息（邮箱、Token）
- 适合截图分享时使用

### AI 模型设置

**选择模型**
- Claude 3.5 Sonnet
- Claude 3.7 Sonnet
- Claude 3 Opus
- Claude 3 Haiku

**锁定模型**
- 开启后禁止 IDE 自动切换模型

**代码库索引**
- 开启后允许 Kiro IDE 索引代码库
- 提升代码补全质量

**信任所有命令**
- 开启后自动执行所有 AI 建议的命令
- 谨慎使用！

### 浏览器设置

**浏览器路径**
- 自动检测：自动查找系统浏览器
- 自定义路径：指定浏览器可执行文件

**无痕模式**
- 开启后使用隐私模式打开浏览器

### 代理设置

**HTTP 代理**
- 自动检测：从系统设置读取
- 自定义：手动输入代理地址
  - 格式：`http://127.0.0.1:7890`
  - 支持 HTTP/HTTPS/SOCKS5

### 机器码管理

**查看机器码**
- 显示当前系统的机器 GUID
- 用于 Kiro IDE 设备识别

**操作**
- 复制：复制机器码到剪贴板
- 重置：生成新的机器码（需要管理员权限）

**支持平台**
- Windows：修改注册表 `MachineGuid`
- macOS：修改 `IOPlatformUUID`
- Linux：修改 `/etc/machine-id`

## 常见问题

### 切换账号相关

**Q: 切换账号时提示 "bearer token invalid"**

A: Token 已过期，切换前先点击"刷新"按钮更新 Token。

**Q: 切换账号后 Kiro IDE 没有反应**

A: 
1. 确保 Kiro IDE 已关闭
2. 检查设置中的"切号自动重置机器 ID"是否开启
3. 手动重启 Kiro IDE

**Q: 切换账号失败**

A:
1. 检查 Kiro IDE 是否正在运行（需要先关闭）
2. 确认账号 Token 未过期
3. 查看错误提示信息

### Token 相关

**Q: 刷新 Token 失败**

A:
1. 检查网络连接
2. 确认代理设置正确
3. 稍后重试
4. 如果持续失败，可能需要重新登录

**Q: Token 多久过期？**

A: 
- 一般 Token 有效期为 1 小时
- 应用会显示剩余时间
- 建议开启"Token 自动刷新"

### 配额相关

**Q: 配额显示不准确**

A: 点击"刷新"按钮更新配额信息。

**Q: 配额用完了怎么办？**

A:
1. 等待配额重置（每天重置）
2. 切换到其他账号
3. 升级到 PRO 订阅

### 导入导出

**Q: 导入 JSON 文件失败**

A:
1. 确认文件格式正确（Social 或 IdC）
2. 检查 JSON 语法是否有误
3. 查看错误提示信息

**Q: 导出的文件在哪里？**

A: 在你选择的保存位置，默认文件名包含时间戳。

### 机器码相关

**Q: 重置机器码需要管理员权限？**

A: 是的，修改系统机器码需要管理员/root 权限。

**Q: 重置机器码有什么影响？**

A:
1. Kiro IDE 会识别为新设备
2. 可能需要重新激活某些软件
3. 建议备份当前机器码

### 其他问题

**Q: 应用启动失败**

A:
1. Windows：确认已安装 WebView2
2. macOS：右键打开应用（绕过安全检查）
3. Linux：检查依赖是否安装完整

**Q: 数据存储在哪里？**

A:
- Windows：`%APPDATA%\.kiro-account-manager\`
- macOS：`~/Library/Application Support/kiro-account-manager/`
- Linux：`~/.local/share/kiro-account-manager/`

**Q: 如何备份数据？**

A:
1. 导出所有账号为 JSON 文件
2. 或直接复制上述数据目录

**Q: 卸载后数据会丢失吗？**

A: 
- Windows：卸载不会删除数据
- macOS/Linux：删除应用不会删除数据
- 需要手动删除数据目录
