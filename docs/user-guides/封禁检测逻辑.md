# 封禁检测逻辑

## API 响应状态码判断

通过调用 `GetUserUsageAndLimits` API 检测账号状态：

| 状态码 | 判定条件 | 判定 | 处理 |
|--------|----------|------|------|
| 200 | - | 正常 | 导入/更新到管理器 |
| 401 | - | token 过期 | 刷新 token 重试 |
| 403 | `reason` = `TEMPORARILY_SUSPENDED` | **封禁** | 标记 banned |
| 403 | 其他情况 | token 无效 | 刷新 token 重试 |
| 423 | `__type` 包含 `AccountSuspendedException` | **封禁** | 标记 banned |

## 封禁响应示例

### 类型一：403 + TEMPORARILY_SUSPENDED

```json
{
  "message": "Your User ID (d-xxx) temporarily is suspended. We detected unusual user activity and locked it as a security precaution...",
  "reason": "TEMPORARILY_SUSPENDED"
}
```

### 类型二：423 Locked + AccountSuspendedException

```json
{
  "__type": "com.amazon.kirowebportalservice#AccountSuspendedException",
  "message": "Your User ID (d-xxx) temporarily is suspended. We detected unusual user activity and locked it as a security precaution. To restore access, please contact our support team to verify your identity: https://support.aws.amazon.com/#/contacts/kiro"
}
```

## 非封禁的 403 响应

### Token 无效（需要刷新，不是封禁）

```json
{
  "message": "The bearer token included in the request is invalid.",
  "reason": null
}
```

## 关键代码（Rust）

```rust
// 401 → token 过期
if status.as_u16() == 401 {
    return Err(format!("AUTH_ERROR: {}", error_msg));
}

// 423 Locked + AccountSuspendedException → 封禁
if status.as_u16() == 423 {
    if let Ok(parsed) = serde_json::from_str::<serde_json::Value>(&error_msg) {
        let type_field = parsed.get("__type").and_then(|t| t.as_str()).unwrap_or("");
        if type_field.contains("AccountSuspendedException") {
            let message = parsed.get("message").and_then(|m| m.as_str()).unwrap_or("账号已被暂停");
            return Err(format!("BANNED: {}", message));
        }
    }
}

// 403 + TEMPORARILY_SUSPENDED → 封禁
if status.as_u16() == 403 {
    if let Ok(parsed) = serde_json::from_str::<serde_json::Value>(&error_msg) {
        let reason = parsed.get("reason").and_then(|r| r.as_str()).unwrap_or("");
        if reason == "TEMPORARILY_SUSPENDED" {
            let message = parsed.get("message").and_then(|m| m.as_str()).unwrap_or("账号已被封禁");
            return Err(format!("BANNED: {}", message));
        }
    }
    // 403 + 其他情况 → token 无效
    return Err(format!("AUTH_ERROR: {}", error_msg));
}
```

## 处理流程

1. 检测到封禁 → 返回 `BANNED:` 前缀错误
2. 前端检测 `errorMsg.includes('BANNED')` 
3. 更新账号状态为 `banned`
4. 封禁账号保留原有配额数据，不会被清零

## 注意事项

- 封禁检测必须精确匹配条件，避免误判
- 403 不能直接判定为封禁，必须检查 `reason` 字段
- 423 必须检查 `__type` 字段包含 `AccountSuspendedException`
- 封禁账号直接报错退出，不会更新配额数据
