# Kiro Account Manager

基于 Tauri 构建的桌面应用（Rust 后端 + React 前端），用于管理 Kiro IDE 账号。

## 核心功能

- 多账号管理：支持 Google、GitHub、BuilderId 登录
- 配额监控：实时查看主配额、试用、奖励使用情况
- 一键切换：快速切换账号，自动重置机器 ID
- IDE 设置同步：代理、模型配置
- MCP 服务器管理：查看、添加、编辑 MCP 配置
- Powers 管理：查看已安装的 Powers
- 主题切换：浅色、深色、紫色、绿色
- 数据导入导出
- 本地存储，数据不上传

## 目标用户

需要管理多个 Kiro IDE 账号或监控配额的开发者。

## 界面语言

应用界面和代码注释均为中文。
